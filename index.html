Fundamental Research Backups

A private, personal-use application that preserves the owner's fundamental investment research and recovery records.

The application creates backup files in a dedicated folder in the owner's Google Drive. It downloads those files again to check their integrity and test recovery. Research scheduling runs separately on the owner's research server.

Google Drive authorization is limited to files created by this application or specifically made available to it. This application does not request access to every file in the owner's Drive.

This public site describes the application only. It does not contain research archives, portfolio information, sign-in credentials or investment recommendations. The application is not offered as a public service.
